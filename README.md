# NotAlone.net

> **You came back. We knew you would.**

At first, NotAlone looks like a very serious monitoring company. The page loads. The copy sounds reassuring. Everything is where it should be.

Then the little things start to change. The site remembers your visits. The errors stop feeling random. And somewhere behind the screen, someone seems very glad you stayed.

NotAlone is a short, interactive browser horror experience. Best played alone, with the sound on, and absolutely not by refreshing the page.

## What to expect

- A polished corporate front with something wrong just beneath the surface.
- Errors that grow more personal each time you return.
- A terminal message from the other side of the screen, and a disconnect button that may not mean what you hope.

Click the navigation. Follow the prompts. Come back later. Pay attention to what it knows.

## Get started

```bash
npm install
npm run dev
```

Open the local URL from Vite and take a look around. For a production build, run `npm run build`; run `npm run lint` to check the code.

## The fine print

Built with React, TypeScript, and Vite. The scares are fictional: the app uses your browser name and screen dimensions in the story, and saves a visit count in your browser's local storage so the experience can progress. It does not access your camera or send personal data to a server. Clear this site's local storage to start the visit counter over.
